# 🏠 MyRoomie

MyRoomie is a backend Java project powering a web platform that allows users to search for PG accommodations by location, view detailed room and building information, and book appointments or reserve rooms.
The system manages comprehensive data including room availability, amenities, and building details, ensuring a smooth and efficient user experience.

---

## 🚀 Features

- 📍 **Location-Based Search** for PG accommodations
- 🛏️ **Room Reservation & Appointment Booking**
- 🏢 **Room & Building Information Management**
- ⏱️ **Real-Time Room Availability Tracking**
- 🏠 **Amenities Listing**
- 🔗 **RESTful API Integration**
- 🗄️ **Scalable Data Storage**
- ✅ **Input Validation & Error Handling**

---

## 🛠️ Getting Started

### Prerequisites

- Java JDK 17+
- Maven or Gradle
- MySQL

### Running the Application

```bash
# If using Maven
./mvnw spring-boot:run

# If using Gradle
./gradlew bootRun
```
